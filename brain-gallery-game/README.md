# 脑内美术馆 Brain Gallery

《脑内美术馆 Brain Gallery》是一款纯前端轻量级互动空间网页游戏。玩家以“访客”的身份进入一座美术馆，依次探索四个代表不同内心状态的房间，并通过四次关键选择生成一张个人内心展览海报。

## 赛道匹配说明

本作品对应“轻量级互动空间”赛道，融合了可探索展厅、互动剧情和个性化海报生成。作品不是问卷页面，而是把心理状态空间化：玩家在真实房间场景中点击展品、阅读碎片、做出选择，最后得到自己的展览结果。

## 核心玩法

1. 领取入场券：输入昵称并选择当前心情。
2. 探索四个房间：记忆温室、噪音剧场、镜像档案室、星空修复间。
3. 每个房间有 1 个核心展品和 2 个可选探索物件。
4. 点击核心展品后做出关键选择，选择会进入人格评分系统。
5. 可选物件会收集碎片，影响最终海报的展览完整度。
6. 完成四次选择后生成个人内心展览海报，可截图分享。

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript
- CSS 3D transform / gradient / shadow / pseudo-elements
- 无后端、无数据库、无登录、无付费 API

## 本地运行

直接打开：

```bash
open index.html
```

或使用任意静态服务器：

```bash
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 部署方式

Vercel：

1. 新建静态项目。
2. 上传 `index.html`、`style.css`、`script.js`、`README.md`。
3. Framework 选择 Other 或 Static。
4. Build Command 留空，Output Directory 留空或使用根目录。

Netlify：

1. 将整个 `brain-gallery-game` 文件夹拖入 Netlify Drop。
2. 或连接 Git 仓库，发布根目录即可。

GitHub Pages：

1. 将文件提交到仓库。
2. Settings -> Pages。
3. Source 选择主分支根目录。

## 作品亮点

- 场景式交互：每个房间都有后墙、地面、家具、光源和透视空间。
- 轻量建模物件：旧相机、麦克风、破碎镜子、机械鸟等均用 CSS 模拟立体质感。
- 选择强绑定人格：四个核心选择直接影响 Memory、Expression、Insight、Repair、Creator、Rebel 六类分数。
- 低门槛演示：完整流程约 3-5 分钟，适合现场快速体验。
- 分享结果明确：最终生成艺术展海报，包含人格类型、隐藏称号、选择回顾和形成原因。

## 交互流程

首页入口 -> 领取入场券 -> 记忆温室 -> 噪音剧场 -> 镜像档案室 -> 星空修复间 -> 最终展览海报

四个房间的核心选择分别对应：

- 记忆温室：如何面对过去的自己。
- 噪音剧场：如何处理外界评价和表达。
- 镜像档案室：如何理解多个版本的自我。
- 星空修复间：如何处理破损、未来和重启。

## 一分钟答辩稿

大家好，我们的作品叫《脑内美术馆 Brain Gallery》，它是一个轻量级互动空间网页游戏。我们把大学生日常里看不见的情绪和自我认知，设计成四个可以探索的房间：记忆温室、噪音剧场、镜像档案室和星空修复间。玩家不是填写问卷，而是在房间里点击展品、收集碎片，并通过四次关键选择生成自己的内心展览海报。

技术上，我们使用纯 HTML、CSS 和 JavaScript 完成，没有后端和外部 API，现场打开浏览器即可运行。视觉上，我们用 CSS 3D、渐变、阴影和伪元素模拟房间结构与展品模型，让作品更像一个真实的互动空间。最终结果会展示玩家的人格类型、隐藏称号、选择回顾和形成原因，因此既有体验感，也有分享欲。后续它可以扩展成校园情绪表达、心理叙事和数字展览类产品。
